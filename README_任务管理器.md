# 任务管理器 (Task Manager) for macOS

## 应用程序说明
这是一个为 macOS 开发的任务管理器应用程序。它可以帮助您管理日常任务，支持任务的添加、编辑、删除和完成状态标记。

## 如何运行应用

### 方法 1: 通过 Finder 运行
1. 打开 Finder
2. 导航到应用程序所在目录
3. 双击 `任务管理器.app` 文件运行应用

### 方法 2: 通过终端运行
打开终端并执行以下命令：
```bash
open "/path/to/任务管理器.app"
```

### 方法 3: 首次运行说明
首次运行时，macOS 可能会显示安全警告，因为这是开发者构建的应用程序，而不是从 Mac App Store 下载的。

绕过安全警告的步骤：
1. 右键点击（或按住 Control 键点击）应用程序文件
2. 从上下文菜单中选择"打开"
3. 在警告对话框中点击"打开"
4. 应用程序将正常启动

## 注意事项
- 该应用程序使用菜单栏图标进行访问，点击菜单栏中的任务图标可以快速查看和管理任务
- 应用程序支持通过状态栏菜单直接显示主窗口
- 所有数据都本地存储在您的计算机上

## 功能特性
- 任务添加、编辑和删除
- 任务完成状态标记
- 任务的历史记录查看
- 菜单栏快速访问
- 本地数据存储
